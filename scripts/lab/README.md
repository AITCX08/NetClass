# scripts/lab — 开发期探索脚本

这里的脚本是**开发过程中的一次性探索工具**，不是运行时组件。

## 为什么留着

它们记录了**每个功能是怎么探明的** —— 遇到同类问题时，翻这里比重新摸索快得多。

按前缀分：

| 前缀 | 干什么的 | 数量 |
|---|---|---|
| `cc-*` | 长春平台探索（进课、点播放、探速率、抓接口、验证记账…） | 30+ |
| `tm-*` | Tampermonkey 方案探索（最终改用 MV3 loader，但这些探清了 TM 的 API 边界） | 40+ |
| `cx-*` | 学习通探索（iframe 结构、测验页、字体解密、提交校验…） | 20+ |
| `webtrn-*` | webtrn 平台探索（研修作业、附件上传、讨论帖…） | 20+ |
| `ss-*` | 生生课堂探索（流地址、速率、结构…） | 20+ |
| `qy-*` / `qiyang-*` | 齐阳平台探索 | 8 |
| `loader-*` | 加载器调试（注入、SW、版本） | 10+ |
| 其它 | 通用调试（页面状态、网络、窗口、探针） | 剩余 |

## 运行时用到的是哪些

**只有 `scripts/` 根目录下的 24 个**（守护、驱动、构建、部署、体检、隧道…）。
**`lab/` 里的不会被任何自动化流程调用**，删掉也不影响运行。

## 用法

大多数脚本是「指定 CDP 端口 + 目标 host」的裸脚本：

```powershell
node scripts/lab/cc-state.mjs 9228            # 长春页态快照
node scripts/lab/cx-quiz-probe.mjs 9227       # 学习通测验页结构
```

**要看某个功能怎么实现的，直接读对应脚本** —— 每个都留了当时的注释与实测结论。
