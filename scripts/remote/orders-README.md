# 每单做单记录规范

这个目录下 **每一单一个子目录**，命名：

```
orders\<yyyy-MM-dd>-<单位简称>\
```

例如 `orders\2026-11-21-基层卫生人员\`。

## 目录结构

```
<订单目录>\
  README.md         ← 做单记录（本文件定义的格式，必填）
  evidence\         ← 证据：页面截图、抓包、接口回显、进度页
  artifacts\        ← 交付物：论文 / 心得 / 证书 / 提交回执
```

## README.md 必填字段

```markdown
# <单位全称> — <订单类型>

| 项 | 内容 |
|---|---|
| 订单日期 | 2026-11-21 |
| 平台 | <平台名> <入口 URL> |
| 任务清单 | <视频学时 / 随堂题 / 发帖 / 论文 …> |
| 完成标准 | <平台怎么算通过> |
| 交付物 | <要交给客户的东西> |

## 账号

| 姓名 | 账号 | 口令 | 状态 |
|---|---|---|---|
| 张三 | xxx | xxx | ✅ 三项 100% |

> 口令只写在本文件，**不要提交到任何仓库**。

## 执行记录

| 1 | 登录 | OK | evidence\01-login.png |

## 关键发现

## 验收结论

- [ ] 平台侧确认三项均 100%
- [ ] 交付物已给客户
```
