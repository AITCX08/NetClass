## 二、必须遵守的 6 条硬事实（都是踩坑换来的）

1. **切任务点只能用 `getTeacherAjax(courseId, clazzid, chapterId)`**
   —— 站内 jQuery.get(`/mycourse/studentstudyAjax`)，自带合法上下文，**完全绕开 `enc校验失败`**。
   直接 `location.href` 拼 `studentstudy?chapterId=...` 会得到 HTTP 200 的**空白页**（正文写"enc校验失败"）。
   补充：实测课程首页 90 个 `studentstudy` 链接**共用同一个 `enc`**，所以带 enc 整页导航也可行。

2. **AJAX 切点后媒体不会自己下载**：`readyState=0 / duration=null / networkState=1`，
   CDP 抓包能看到 `sd.mp4` 返回 206 却立刻 `ERR_ABORTED`。
   **唯一有效动作是显式 `video.load()`**（`agent.js` 的 `A.kick()`）；
   只调 `play()` 没用，真实鼠标点播放按钮也没用（那时按钮是 0×0 未初始化）。

3. **倍速被硬锁 1x**：站点在 `ratechange` 后**同 tick** 把 `playbackRate` 写回 1。
   解法（`runs/cx/cx-rate.js`）：在 `<video>` **实例**上 `defineProperty('playbackRate')`，
   getter 恒返回目标值（站点读到目标值就不再触发还原），watchdog 每 3s 用**原生 setter** 压回真实值。
   上限 2x（平台高倍速风控会清进度）。

4. **任务点枚举**：叶子 = 自带 `.jobUnfinishCount` 的 `H5`（值是未完成数）；
   只认 `[onclick^="getTeacherAjax"]`（任务点页目录没有 href）；容器节点没有 `.jobUnfinishCount`，要跳过。

5. **完成判定**：树里叶子的 `un===0`。**侧边栏只随整页刷新更新**（AJAX 不刷新它），
   所以驱动每 3 个视频结束、或连续 4 个点"无内容"时整页 reload 拿权威状态。

6. **提交/弹窗**：一点提交就弹原生 `alert`，**JS 线程被阻塞后所有 `Runtime.evaluate` 全部超时**。
   必须挂 `Page.javascriptDialogOpening` 自动 `handleJavaScriptDialog`。
   另外表单的 `#enc` 由异步 `validateTimeNew` 写入，**enc 为空时服务端只"保存"不"提交"**。

## 四、加密字体（font-cxsecret）解码要点

- 题面汉字用 `@font-face` 内嵌的 `font-cxsecret`：**码位是 PUA 乱码、字形是正确的汉字**。
- **密文字符的判据必须是"glyphId 有效且有轮廓"**（正文普通汉字会落到 `.notdef(0)`）；
  按"带 cxsecret 样式"筛会把正文混进来（实测踩过）。
- 字体是**每页重新子集化**的（约 60 个字），所以必须每页解一次。
- 指纹库**只能用 GB2312 6763 字**：CJK 全区含大量日文汉字/异体字，
  它们的字形比简体目标更接近（如 `恣→俧` 而真值 `法`），实测准确率 **27% → 85%**。
- 应对笔画粗细差：参考字形做**多档腐蚀/膨胀变体**，取最优距离。
- 低置信度字不影响语义（DeepSeek 能靠上下文还原），实测题面可读性良好。
